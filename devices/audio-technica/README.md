# Audio-Technica profiles

No devices here yet. When you add one:

```
audio-technica/
  microphones/
    <id>/
      device.conf
  capture-cards/
    <id>/
  mixers/
    <id>/
```

Create only the category folders you need. Each device must live at
`audio-technica/<category>/<id>/device.conf` (never directly under
`audio-technica/`).

See [../README.md](../README.md) for the full profile format.
